# Contributing / 贡献

Read AGENTS.md, keep changes scoped, and describe the problem and validation in your pull request. Run `npm test`, `npm run lint` and `npm run build` for code changes; run `node scripts/simulate-game.ts` when changing probabilities. Preserve third-party licenses and never submit private media or credentials.

先阅读 AGENTS.md。提交请求说明问题、改动及验证结果；代码变更运行测试、检查和构建，概率调整追加模拟。保留素材许可，不提交私人媒体或凭据。
