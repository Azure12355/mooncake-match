# Security / 安全

Do not post credentials or exploit details in public issues. Report suspected vulnerabilities through GitHub private vulnerability reporting when available; otherwise ask the maintainer for a private reporting channel without sharing sensitive details. No response-time guarantee is offered.

不要在公开 Issue 中发布凭据或漏洞利用细节。优先使用 GitHub 私密漏洞报告（若已开启）；否则先向维护者询问私密报告渠道，不公开敏感细节。不承诺固定响应时限。
