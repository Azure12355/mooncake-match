# 月饼消消乐 PRD

版本：v1.0 · 2026-09-22
状态：核心规则经逐项确认并已实现；收尾交互采用建议默认值；初始难度尚未试玩验证。

## 1. 目标与范围

用 React + Vite + TypeScript 制作一个纯前端中秋主题交换三消小游戏。只有一个游戏主界面，设置和结算使用覆盖式弹窗。手机竖屏优先，电脑居中呈现相同竖版布局。单关反复游玩，无后端、账号、支付、排行榜服务或多关卡系统。

当前交付：React 游戏主界面、完整单局逻辑、独立游戏素材及本地音频。规则和存储单元测试已通过，浏览器操作、视觉还原和实际难度尚待验收。

## 2. 主界面

从上到下为标题与中秋背景、设置入口、分数/剩余步数/目标进度、8 列 7 行棋盘、四种道具。最高分在结算展示。动态数字与文案由 React 渲染，美术图片不烘焙业务数值。

所有视觉素材通过 imagegen 内置工具生成：夜景背景、标题、8 种棋子、4 种道具、通用面板、通用按钮、设置图标、消除星光、胜负兔子。通用面板复用于棋盘底板、状态面板和弹窗；通用按钮搭配文字用于重玩、关闭、取消、确认及声音开关。选中、禁用、按压状态通过透明度、缩放和高亮处理，不新增图标依赖。

## 3. 初始配置

| 项目 | 规则 |
|---|---|
| 棋盘 | 8 列 × 7 行 |
| 棋子 | 普通花纹月饼、玫瑰月饼、抹茶月饼、雪皮月饼、蛋黄月饼、可可月饼、兔子、灯笼 |
| 步数 | 20 |
| 目标 | 普通花纹月饼 12、兔子 8、灯笼 8 |
| 得分 | 每消除一个棋子 10 分，无连锁倍率 |
| 道具 | 锤子 3、换一换 3、彩虹月饼 1、月光炸弹 2 |

每局随机开局，无现成三连，且至少有一次有效交换。基础随机权重仍均等；开局优先筛选至少 10 组有效交换的棋盘。生成最多尝试 24 次，若未达到 10 组则选有效交换最多的候选，仍确保无现成匹配且至少有一次有效交换。消除后的补棋按下述连消助攻处理，不再是完全独立随机。

## 4. 交换与消除

支持依次点击两格，以及从棋子向上下左右滑动交换。只有正交相邻两格可以交换；点击非相邻格改为选中新格，点击已选格取消选择（实施默认值）。

交换形成横向或纵向连续至少 3 个相同棋子才有效。无效交换回弹、不扣步；有效交换扣 1 步。T/L 形交叉匹配取所有匹配格的并集，同一棋子只消除和计分一次。4 连、5 连不生成特殊棋子。

连消助攻：每轮先自然下落、随机补棋；若没有产生新匹配，以 95%、90%、80%、65%、40%、15% 的递减概率尝试让新补入棋子凑成真实三连，第 7 次补棋起不再助攻。只调整刚补入的棋子，保留现有棋子的类型和位置；无可行三连窗口则正常结束。助攻也适用于消除道具。每次操作最多消除 10 轮，达到上限后若仍存在匹配，则免费重排稳定棋盘并交回操作权，重排不计分。

连消越往后，消除与下落动画越快：每轮从合计 550ms 缩短到最低 300ms，音效轻微升调，并突出显示连消次数。全部真实消除仍按每格 10 分，不增加倍率。

流程：交换 → 查找全部匹配 → 同时消除 → 更新分数和目标 → 向下掉落 → 顶部补充 → 再检测匹配，重复至稳定。连锁不额外扣步，连锁消除和道具消除均计入目标。目标显示最多到所需数量，但多消除的棋子仍正常得分。

处理动画与连锁时锁定棋盘、道具及重开等影响对局的操作，避免重复结算。音乐开关不影响逻辑。

## 5. 道具

| 道具 | 操作与效果 |
|---|---|
| 锤子 | 选道具再选一个棋子，消除该棋子；本版没有障碍物 |
| 换一换 | 直接随机重排现有棋子，不扣步、不得分；重排后无现成匹配且存在有效交换 |
| 彩虹月饼 | 选道具再选一个棋子，消除棋盘上所有同类棋子 |
| 月光炸弹 | 选道具再选中心格，消除中心及周围 3×3；边角取实际棋盘范围 |

所有道具不扣步，成功使用才扣一次，次数为 0 时禁用。可取消选中道具或切换道具，取消不扣次数。道具消除后照常下落、补齐、连锁。新一局恢复次数。

## 6. 胜负与死局

每次操作的全部连锁结束后，按顺序判断：

1. 三项目标全部完成：胜利。
2. 未完成且步数为 0：失败，即使还剩道具也不能继续。
3. 否则继续；若没有有效交换，自动免费重排并提示。

最后一步通过连锁完成目标也获胜。结算后禁用棋盘和道具，防止继续加分。自动重排不扣步、不消耗道具、不改变分数和目标进度，优先保留棋子数量组成；若当前组成无法形成合适排列，重新生成可玩棋盘（防死局实施兜底）。重排本身不触发消除收益。

## 7. 弹窗与声音

以下为收尾交互默认方案：设置包含背景音乐开关、音效开关、玩法说明和重新开始。对局中重新开始需确认，取消返回原局。结算弹窗显示胜负、本局分数、最高分及“再玩一次”。弹窗使用键盘可操作的按钮、可见焦点和语义化标题。

音乐及交换、消除、道具、胜利、失败音效在首次用户交互后启用，不能绕过浏览器自动播放限制。背景音乐循环播放；切后台暂停，返回后根据设置恢复。音乐和音效分别记忆开关。音频不属于 imagegen 输出，工程提供独立本地合成音频素材及生成脚本，不冒充 AI 生成的录音。

## 8. 本地存储

localStorage 仅保存最高分、音乐开关、音效开关。最高分随已完成结算的消除得分更新；刷新丢弃当前棋盘、步数、目标与道具次数，开始新局。存储不可用时仍可游玩，只是不跨刷新保存。

## 9. 动画与适配

交换/回弹、消除缩放与星光、下落和补齐、目标进度反馈。优先 transform/opacity，避免每帧大面积重绘。移动端棋盘区域正确处理手势，主界面按可用视口宽高等比例缩放，标题、棋盘、道具及底部操作完整呈现在同一屏；极矮横屏下棋子会相应缩小，建议竖屏操作。设置与玩法弹窗独立于缩放画布，内容过长时允许弹窗内部滚动。尊重 reduced-motion 设置，减少视觉动画但保留完整逻辑。

图片需要透明边缘、完整轮廓及统一光源。背景为不透明竖图，棋子和道具为独立透明 PNG。源图片保留，后续如需压缩派生 WebP 须核验透明度与视觉质量。

## 10. 验收标准

- 棋盘始终为 56 格，稳定时无空格、无未处理匹配，至少存在有效交换。
- 无效交换不扣步；有效交换只扣 1 步；连锁不重复扣步。
- 交叉匹配不重复计分，目标仅由对应棋子消除推进。
- 四种道具次数、取消、边角范围和目标计入均正确。
- 最后一步优先判胜；结束后不接受新操作；无步数时不能使用道具续命。
- 自动重排无资源消耗、无额外收益，仍可继续游玩。
- 重玩重置全部对局数据但保留最高分与声音设置。
- 刷新不恢复对局；首次交互前无自动播放声音。
- TypeScript 检查、lint、构建和核心规则单元测试通过。
- 视觉验收依据用户截图；确需浏览器交互须先获明确同意，不能把构建通过当成视觉验收。

## 连消机制模拟

300 局固定种子模拟，随机选择有效交换，不使用道具：连消发生率由 17.8% 提高至 96.2%，平均每手由 1.21 轮/3.78 格提高至 4.35 轮/13.91 格。现有目标下模拟通关率从 20.3% 提高到 99.7%，平均 8.65 步结束，属于明显偏解压的难度。以上是规则模拟，不是玩家实测或留存数据。方法及完整结果见 BALANCE.md。
