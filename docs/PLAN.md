## 实现方式

规则层预先生成一轮操作的状态步骤，React 按步骤播放交换、消除、掉落和结算。保留棋子的稳定 ID 做位置过渡，避免引入额外状态库或动画库。输入立即加锁，步骤播完才恢复操作。

连消机制已改为新棋子递减助攻，每手最多 10 轮，随后稳定棋盘并交回操作权；详见 PRD 和 BALANCE.md。自动重排和道具重排优先保留棋子组成，128 次尝试仍无合适排列时重新生成。
